# Amazon Homepage UI

A simple static storefront homepage built with HTML and CSS. It recreates the look of an Amazon-style navigation bar, category cards, and footer for practice.

## Preview

Open `index.html` in a web browser to view the page. No build tools or installation are required.

## Project files

- `index.html` — page structure and content
- `style.css` — layout, colors, and styling
- `amazon logon.jpg` and `box*.jpg` — images used by the page

Keep the image files in the project folder so the image paths in the page continue to work.
